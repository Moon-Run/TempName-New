# 初步思想：基础 tile 顺序 + 最晚贡献优先 + 选择性压缩

更新日期：2026-10-03。本文描述研究设想；已实现内容、实验结果与近期执行计划见 [only-tile.md](only-tile.md)，实验口径见 [base.md](base.md)。

## 1. 优化目标

对输出 tile `t`，源 rank `r` 的完整贡献到达时间记为 `A(r,t;π)`，其中 `π` 是所有 rank 的调度方案。其贡献汇合时刻与偏斜为：

$$
T_{\mathrm{join}}(t;\pi)=\max_r A(r,t;\pi),\qquad
S_{\mathrm{join}}(t;\pi)=\max_r A(r,t;\pi)-\min_r A(r,t;\pi).
$$

这里的完整贡献包含该来源所需的全部局部计算/fragment；单个 CTA 结束不一定代表完整贡献就绪。`T_join` 表示贡献齐备，不直接等于最终归约/消费结束，更不直接等于完整 GEMM-RS 完成时间。

可以概念性地将到达时间拆为计算就绪、排队、Q、传输和DQ，但实际融合路径未必能独立测出每一项，也不能重复计入重叠成本。BF16重排阶段没有通信量化，Q/DQ项为零；当前接收端采样测到的是包含标记传播与轮询误差的观察时刻。

最终以**无插桩完整 GEMM-RS 延迟**验收，模型接入后另测完整optimizer step。贡献到达尾部、最后来源和join skew用于解释；只缩小skew不足以证明优化，因为它也可能来自推迟早到贡献。稀疏样本的分位数须标明覆盖范围。

## 2. 两层 tile 重排：两种基础顺序都保留

这个设想没有内在矛盾，可以研究，但收益需要验证。交替与远端优先作为两种可选的基础顺序，各自在其上叠加“预计最晚贡献优先”，形成两条候选路线：

| 基础顺序 | 第一层决定什么 | 第二层如何叠加 |
| --- | --- | --- |
| 本地/远端交替 | 按目标分区分配生产槽位或分组节奏 | 在当前槽位允许的分区/窗口内，优先选择预计影响尾部的贡献 |
| 远端优先 | 优先安排远端分区或对其赋予顺序偏好 | 在允许的远端候选中按预测优先级排序；允许有限跨组调整时单独定义规则 |

TP=2可采用“本地、远端”循环；TP=4需要覆盖一个本地和三个远端分区，例如“本地、远端1、远端2、远端3”。不能强行固定1:1比例而遗漏或重复任务。当前`remote_first`实现只是rank+1分区偏移，不保证非方形下所有远端tile先于本地；若实现严格“全部远端在前”，须作为新基础顺序独立验证。

### 先明确顺序约束，再加入时间优先级

**严格基础顺序与无条件全局最晚优先不总能同时满足。** 例如交替序列下一槽位要求本地，而全局最晚贡献属于远端：若提前该远端，就打破严格交替；若保留本地槽位，就只能在允许集合内选择最晚候选。远端优先也可能将已经成为瓶颈的本地贡献压到后面。

原型先采用受约束版本：给定基础顺序`π_base`、有限前瞻窗口`W`和分组/局部性约束，从合法候选中挑选贡献或任务组，等分或预测不可信时保留基础顺序。无法在这些约束内提前的贡献如实记录；严格约束没有可用自由度时，允许结果退化为基础顺序。

之后可单独实验软约束版本：在预先限定的位移或分区配额内，允许打破少量基础槽位。两种约束分别出结果，不能将完全覆盖基础顺序的全局排序仍称作严格交替或严格远端优先。

### “最晚”依据与调度粒度

每种基础顺序分别建立预测`Â(r,t;π_base)`，先识别一个tile内的近临界贡献集合：

$$
\mathcal C_\delta(t;\pi)=\{r:\max_q\widehat A(q,t;\pi)-\widehat A(r,t;\pi)\le\delta\}.
$$

`δ`结合预测不确定性预先设定，用于保留多个近似并列的最后贡献。不能把原始顺序下最后到达的来源永久标为关键来源，也不能在未校准的不同GPU绝对时钟间直接排序；跨tile比较需有共同时间原点或可解释的相对基准。

“某tile内最晚”仅是候选条件。一个很早完成的tile也有最后贡献，未必影响全算子尾部。优先级还应考虑该tile接近整体尾部的程度、提前后可能减少的等待，以及对被后移tile、局部性和接收端争用的影响。原型可以先用低开销启发式，无需一开始就求出精确最优解。

重排单位必须是现有调度器能合法移动的tile或任务组；若一个贡献由多个Stream-K任务共同产生，应保持依赖和工作区索引一致，不能假定可以任意调动单个fragment。逻辑映射优先也不保证硬件实际先完成，最终以观测与完整算子计时确认。

### 离线生成、有限更新、独立验证

1. 在两种基础顺序下分别获取可解释、低扰动的到达样本，按shape/TP/拓扑建模；先验证最后来源及尾部排序的可预测性。
2. 在合法窗口/分组内生成候选静态映射。模型可以汇总多个rank的信息，运行时各rank执行预生成映射；不依赖每个tile在线交换全局队列状态。
3. 对新映射重新估计或采样到达时间。它会改变就绪、排队、争用和最晚来源，不能假定原时长完全不变，也不能假定各tile都能同时被提前。
4. 预先限制更新次数、移动幅度和候选数量；改善不足或预测不可靠时回退对应基础顺序。使用独立样本/作业验证，防止对同一批时序噪声反复拟合。
5. 正式无插桩计时包含运行时索引、查表和额外访存开销；离线构建/校准成本另报，并说明复用范围。

当前两种静态基础映射及“交替+到达优先”“远端优先+到达优先”的一次离线拟合原型均已完成TP4测试；原型未显示额外性能收益。采样作为探索性排序标签，未被视为已通过低扰动机制验收。2026-10-03先行TP4 v2 tail复验仍无叠加增益；单节点TP8仍需重新校准并生成八来源映射。

### 历史实测原型与完整设想的差距（2026-10-03）

历史实测原型对应的入口为[TP4排序代码](../../../tools/a800/arrival/plan.py)，单节点8卡扩展见[TP8排序代码](../../../tools/a800/arrival8/plan.py)。它对每个来源计算两次校准中`A(r,t)−max_{q≠r}A(q,t)`的中位数；只有该值大于两倍轮询周期才给正分，否则置零。每个目标分区的连续16个合法槽位内按分数稳定降序排列，同分保留原序。改动逻辑tile索引后再执行原基础swizzle，依赖保持一致，运行时查表。

因此，它实现了“两种基础顺序上叠加受约束优先级”，但**没有完整实现本节提出的尾部代价模型与迭代更新**：分数只有最后贡献相对其他来源的滞后量，没有该tile影响全算子尾部的权重、移动收益/被后移代价或局部性惩罚；近似并列来源被置零，没有联合提前多个近临界贡献；第三轮仅验证原基础顺序下的最后来源判断，未重新采样重排后的到达时间。前两次采样最后来源不一致时，中位滞后仍可能产生正分，也未用跨次一致性作独立准入。

16槽位是该原型固定的工程参数，未证明最优。交替版保留每个槽位的目标分区，因此TP8仍是一个本地、七个远端分区循环；远端版保留当前rank+1映射的分区节奏，并非另行实现严格全远端优先。4卡负结果仅针对这套启发式；单节点8卡将保持算法不变，单独检验TP与局部K改变后的结果。

## 3. 在重排之上增加选择性压缩

重排改变贡献产生顺序；选择性压缩只处理重排后仍接近关键窗口、且通信净收益为正的远端贡献。概念性净收益为：

$$
\Delta T(r,t)=T_{\mathrm{transfer}}^{\mathrm{BF16}}-
(T_{\mathrm{Q}}+T_{\mathrm{transfer}}^{\mathrm{FP8}}+T_{\mathrm{DQ}}).
$$

实际验收还须计入scale/元数据、额外访存和并发争用，并满足预先固定的数值预算。其余贡献保留BF16。

例如四个贡献在8、9、10、14 μs到达；若重排只将最晚者提前到11 μs，随后压缩又将其提前到9.5 μs，且其他贡献时刻不变，则汇合时刻从14降至10 μs，原先10 μs的贡献成为新的最后者。这是说明关键集合变化的理想例子，不是对真实调度影响的保证。

压缩与重排均会改变关键集合，因此每次更新后重新估计，限制迭代次数。最终还须确认归约、同步和完整算子确实变快。

## 4. 实施阶段与对照

这里保留研究思路的阶段0–3；近期执行编号T0–T4见 [only-tile.md](only-tile.md)。

| 阶段 | 工作 | 通过条件 |
| --- | --- | --- |
| 0：到达剖析与预测准备 | 修正位置/子集准入，在两种基础顺序下测完整贡献观察、最后来源和尾部关联 | 扰动、轮询误差和样本覆盖可解释；预测在独立样本有效 |
| 1：BF16重排only | 先固定基础映射与局部性消融，再分别实现交替+到达优先、远端优先+到达优先；软约束另列 | 正确性与映射通过，完整算子收益可重复；叠加收益须对各自基础策略计算 |
| 2：选择性压缩only | 固定原始顺序，先测Q/DQ成本与误差，再选择关键窗口内的远端贡献 | 净收益覆盖全部新增成本，误差预算通过 |
| 3：重排+选择性压缩 | 在通过阶段1的排序上重估关键集合，比较全量与选择性压缩 | 联合收益超过简单组成部分，报告选择/索引开销与失效配置 |

BF16主消融至少包括原始Flux、交替、远端优先、交替+到达优先、远端优先+到达优先。以相同移动预算的无时间信息排序作为控制，可检查收益是否确由预测信息带来；分组局部性候选另列。两条叠加路线都保留，不预先认定哪种基础顺序最终更好，也不保证叠加必然优于各自基础。

模型级保留原生Megatron参考。进入压缩阶段后再加入Flux全量远端压缩、选择性压缩only、联合方案及可比的Megatron-LM+量化参考，明确压缩位置与误差预算。已有BF16收益、未来到达优先增量和未来压缩增量分别报告。
