# H100 优化思路：三个结合方向

本文将 [idea.md](idea.md) 中的机制按优化对象归并为三个大方向：**选择性量化通信、数据重排与复用、保序融合与批量归约**。它们分别关注数据用什么形式传输、何时生产和消费，以及怎样减少计算链中的重复工作。

## 一、基于到达信息的选择性量化：把压缩用在关键远端贡献上

行并行投影中，每个输出 tile 都要汇合多个 GPU 产生的部分结果。不同来源的贡献到达时间不同，较晚到达的贡献可能限制整个 tile 何时收齐。统一量化所有远端数据虽然可以缩小传输载荷，也会给所有这些贡献增加编码、解码和尺度处理的工作，并引入量化误差。

核心想法是**以来源和物理 tile 的组合为单位，根据到达信息选择值得压缩的远端贡献**：先在 BF16 基线路径下离线观察各来源的到达情况，识别可能造成较晚汇合的近临界贡献；再在有限预算内选择其中的远端贡献，用 FP8 和相应尺度表示，其余贡献仍走 BF16，本地贡献始终保留 BF16。量化编码与投影计算的输出阶段结合，接收端依据同一份物理贡献标识选择解码或直接读取。

这个方向把**通信收益、编解码开销和精度影响**放在一起考虑，而不是把压缩比例作为唯一目标。选择计划由离线观测生成并冻结，运行时不会根据每次到达情况动态调整；它是针对潜在关键贡献的启发式选择，并不保证每个被选中的贡献都能带来净收益。

## 二、面向数据流的重排、预取与生命周期复用

数据是否能及时被消费，既取决于生产顺序，也取决于读取时机和数据能够保存多久。这个方向从生产、接收和前后向复用三个位置组织数据，分别作用于行并行输出投影与列并行输入：

- **生产端重排：** 将不同目标 GPU 的 tile 生产槽位交替安排，让各目标持续获得贡献；在不改变目标归属的前提下，再依据离线到达信息调整同一目标内部的 tile 顺序，优先安排可能拖延汇合的贡献。重排改变的是生产位置，不改变物理 tile 的身份，也不改变它对应的量化选择。
- **接收端预取：** 数据发布后，在处理当前来源时提前读取下一来源的数据，让读取与解码、归约计算有机会重叠。根据贡献格式分别读取 FP8 或 BF16，并通过连续数据打包改善读取组织；来源的累加顺序和原有舍入保持不变。这里的预取发生在接收端消费阶段，不代表提前启动网络传输。
- **跨前后向复用：** 对 QKV 和 FC1，将前向 AllGather 得到的完整输入由当前计算节点独立持有，保存到反向权重梯度计算使用，从而消除对同一输入的反向重复 AllGather。该方法以更长的激活保存时间和额外显存换取重复通信的减少，原前向收集和输入梯度通信仍保留。

三者作用于不同时间尺度：重排决定**先生产什么**，预取决定**何时读取已发布的数据**，激活复用决定**数据能否跨前后向继续使用**。其中重排和第一点的量化共用同一份离线到达信息，但各自改变的对象不同。

## 三、保持数值语义的计算融合与批量归约

训练中有些开销来自计算结果在多个算子之间反复写回、读取，或来自大量小张量各自启动统计操作。可以在保留原有依赖、归约顺序和必要舍入的前提下，重新组织这些计算，让数据在更短的路径内被消费。

- **投影结果的消费融合：** 在接收端按原顺序完成各来源归约后，接着完成 bias 和 residual 加法，再写出最终结果。保留两次独立的 BF16 舍入和后续 LayerNorm，减少中间结果的读写与独立算子提交。
- **注意力中间态消除：** 在 mask 和 softmax 前后向中直接消费掩码，并在片上形成反向所需的乘积，直接产生分数梯度，避免仅供链内使用的临时矩阵以及原位 view 修改带来的梯度重建。保留原 softmax 的归约与舍入；QK、PV 及其反向矩阵乘法仍按原路径执行。
- **多张量统计归约：** 将优化器步尾逐参数的零梯度统计组织为跨张量分块计数，再按原参数顺序完成 FP32 汇总。可并行的整数计数与必须保序的浮点累加分别处理，减少逐张量扫描和提交，同时保留原跨卡标量归约及后续优化器依赖。

这三个例子共同体现的是：**合并数据访问和执行过程，但保留决定结果的数值边界**。这里的保序要求针对融合与统计路径；第一点的 FP8 选择性量化本身仍会引入量化误差。

三个方向可以组合在完整训练路径中：到达信息帮助选择传输表示和生产顺序，数据调度与复用减少等待及重复通信，计算融合与批量归约缩短后续消费和统计路径。它们作用于不同阶段，组合是否有效仍取决于实际依赖、资源竞争与整体执行情况。
