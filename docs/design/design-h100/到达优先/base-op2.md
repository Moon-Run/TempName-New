# H100 到达优先 op2：同量化成对行调度的两次50步实测

更新：2026-10-20。依据回传提交 `5ec4b231` 及批次 `arrival-op2-order-2x-50steps-20261020-161635-645726`，汇总同codec筛选和 `compare1`、`compare2` 的完整训练结果。方案见 [op-2.md](op-2.md)。两份预检及严格报告均通过本轮CPU离线重算，原始实验文件未修改。

## 1. 结论：调度确实生效，但没有获得稳定整步收益

**以“比原A完整训练step快至少1.5%”为目标，本次改动没有达标，也没有显示可重复的端到端加速。**

- **执行层面生效。** 筛选选出 Attention `g=8`、MLP `g=4`；实际GPU mapping分别改变3072/4096、3584/4096个槽位，两个角色均非identity。编码、解码及其他非调度源码与A一致。
- **单算子校准只有小幅收益。** 所选Attention和MLP的配对耗时下降分别为 **+0.638%**、**+0.548%**，通过既定筛选区间规则；平均每次仅节省约1.239 μs、1.458 μs。
- **完整step未验证收益。** 两次S/A配对耗时下降分别为 **−0.056% [−0.416%, +0.323%]**、**−0.070% [−0.407%, +0.245%]**，95%区间均跨零，四个单轮区间也均跨零。
- 两次合并平均A为 **535.492 ms/step**，S为 **535.829 ms/step**；S描述性均值约慢 **0.337 ms/step（0.063%）**。不能据此认定稳定退化或严格等效，但明确不支持1.5%的目标幅度；两次区间上界也远低于1.5%。

批次状态为 `status=completed`、`target_validated=false`、`acceptance_status=not_validated_1.5_percent`。这是**实验完整完成、性能目标未通过**，不是未运行、没有重排或数值失败。当前不应把S作为“已经证实更快”的替代基线。

## 2. 两组定义与固定条件

| 项目 | A：原交替基线 | S：成对行生产顺序 |
| --- | --- | --- |
| 生产顺序 | 原基础交替，目的地内按两行先后遍历 | 保持相同目的地槽位，按所选g交织两行 |
| Attention / MLP运行参数 | `32 / 32`，identity | **`8 / 4`** |
| 远端量化 | 每来源448个远端tile全部量化 | 相同 |
| 编码与解码 | 原融合v2、H128/E4M3、原CTA解码 | 相同 |
| 归约、工作区与输出 | 原BF16来源顺序和逐次舍入、单工作区、输出clone | 相同 |
| 跨rank同步 | 发布屏障＋复用屏障 | 相同 |

三项来源核验一致：

1. 两组登记源码各351个文件，只有 `threadblock_swizzle.hpp` 和 `phase6_host.hpp` 不同，**其余349个源码文件哈希相同**。
2. 两角色物理mask均相同，每来源448/448个远端贡献全部量化，本地贡献保持BF16。
3. 两次完整比较共用同一个冻结选择、相同运行库登记及角色计划；完整模型预检确认两组均执行原CTA解码器。

本次没有C组，也没有此前撤回的warp解码优化组。S/A只衡量生产调度的变化，包括实现该调度所需的索引计算开销。

环境：单节点 `gxn75`，8×NVIDIA H100 80GB HBM3、每卡132SM；PyTorch2.6.0+cu124、运行CUDA12.4、NCCL2.21.5，`NCCL_NVLS_ENABLE=0`。模型为GPT6.7B：32层、H4096/FFN16384、32 heads、序列2048、micro batch1/global batch4、TP8、BF16，seed1234、token_seed4321、padded vocab33792。每个optimizer step包含4个微批、8192 token和256次目标前向投影。

## 6. 为什么筛选通过，整步仍未达标

本次最明确的问题是**绝对收益规模不足，而筛选条件只要求算子正收益**。

以新批次A的535.492 ms/step计算，1.5%需要减少 **8.032 ms/step**，相当于256次目标投影平均各减少 **31.376 μs**。实际单算子均值节省约为1.239 μs和1.458 μs：

```text
假设每次算子节省能原样迁移到训练：
128 × (1.239 + 1.458) μs ≈ 0.345 ms/step
0.345 / 535.492 ≈ 0.064%
```

这是用于比较数量级的**条件估算**，不是实测整步归因、理论上界或收益保证。它已经远小于1.5%，也小于本轮整步统计的不确定性范围。不能期待通过“筛选时略微更快”自然达到整步目标。

完整模型中的缓存及层间交互变化，可能使微基准收益进一步减弱或改变；但本次没有无扰动的逐阶段证据，不能断言某个具体开销抵消了收益，更不能据此宣称已证实L2命中率改善。

这批结果支持的判断是：**同量化条件和调度接入已验证，成对行顺序在本次校准中有小幅算子差异，但未验证完整训练加速。** 当前应保留A作为性能基线；若继续研究，候选筛选需要与8 ms级整步预算挂钩，不能只通过降低正收益门槛或继续微调g来宣称达标。本次仅总结结果，未修改算法、参数或启动新实验。
