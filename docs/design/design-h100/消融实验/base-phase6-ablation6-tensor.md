# H100 GPT6.7B TP8 消融实验6：对齐朴素量化baseline的50步实测

更新：2026-10-19。依据回传提交 `42d048eb`，汇总批次 `ablation6-then7-3x-50steps-20261019-162154-480841` 下消融6的三次独立比较。**三次均完成，每次50个正式窗口，合计150窗口、7500个正式optimizer step、1200份正式rank记录。** 三次独立预检及严格报告均通过CPU离线重算。方案见[消融6定义](消融实验6-对比baseline.md)，后续三次消融7另见[消融7结果](base-phase6-ablation7.md)。

## 1. 实测结论

- **C的完整step耗时最低：三次合并515.866 ms/step。** 相对A、B、Flux朴素量化、Megatron朴素量化的合并均值下降分别为3.610%、3.482%、47.860%、48.872%；三次各自的C/其他组配对区间均为正。
- **共用同一朴素量化后，Flux baseline仍略快于Megatron baseline。** 合并均值989.377对1008.970 ms/step，下降1.942%；三次配对下降分别为1.738%、2.204%、1.883%，95%区间均为正。这是共享codec条件下的整步实现差别，仍包含GEMM和临时张量管理等因素。
- **旧到达调度B/A的优势没有在三次中稳定复现。** 三次配对下降分别为+0.392%、−0.233%、+0.237%；第二次点估计为负且区间跨零。合并均值B比A快0.133%，不足以单凭该均值宣称稳定收益。
- 两个朴素baseline的50步loss轨迹完全相同，A/B轨迹也完全相同。C末步loss为3.057346e-04，高于其余组；这反映本固定合成微批上的短程训练轨迹，不能替代真实语料的精度或泛化结论。

## 2. 比较范围与固定条件

| 组别 | 前向计算与量化路径 | 远端量化范围 |
| --- | --- | --- |
| C | 原candidate实现，交替＋原到达表、双工作区、实例持有配置/输出 | 预算上限1/64，正分选择性mask |
| A | 固定融合v2，基础交替、单工作区、逐次配置/复位、输出clone | 全部远端贡献 |
| B | 与A相同的融合v2与生命周期，使用原到达表 | 全部远端贡献 |
| Flux朴素 | 原生SM90 GemmOnly，然后调用共享TensorTacoRS | 全部远端贡献 |
| Megatron朴素 | 原生Megatron GEMM，然后调用同一TensorTacoRS | 全部远端贡献 |

两个baseline共用H128/E4M3编码、All-to-All通信、解码及按来源累加；共享codec与参考实现的源码哈希和实际调用数均核验一致。所有组的本地贡献保持BF16。“完整量化”指远端来源贡献，不是整网权重量化；本表baseline本身带有朴素量化，原生BF16基线需另场测量。

C/A、C/B同时涉及mask、codec、工作区及配置/输出生命周期差别；A/Flux朴素也同时改变GEMM、调度与融合方式。本实验比较整体实现组合，不能把C的全部收益归因于选择性量化覆盖率。

环境为单节点 `gxn75`、8×NVIDIA H100 80GB HBM3、每卡132 SM，PyTorch2.6.0+cu124、运行CUDA12.4、NCCL2.21.5，`NCCL_NVLS_ENABLE=0`。模型为GPT6.7B：32层、H4096/FFN16384、32 heads、S2048、micro batch1/global batch4、TP8/DP1/PP1/CP1、BF16，seed1234、token_seed4321、padded vocab33792。所有组均覆盖32个Attention输出投影和32个MLP输出投影。

每窗口独立重置模型，预热10步后正式50步；每步4个微批、8192 token，每窗口409600个正式token。完整step包含前向、反向、通信、optimizer更新和清梯度，耗时为 `max(八rank elapsed_seconds) × 1000 / 50`。步数由 `execution_timing`、冻结worker配置和全部rank轨迹共同核验；继承的构建 `config.timed_steps=20` 仅为历史溯源元数据，不能作为本次计时分母。累计步数表示多个独立窗口的工作量。

## 6. 量化覆盖率、数值与loss解释

本次C仍是 **1/64上限（1.5625%）**：Attention选中53/3584个远端贡献（1.479%），MLP为50/3584（1.395%），合计103/7168（1.437%）。A/B和两个朴素baseline均覆盖全部远端贡献。预算与实际mask见冻结计划；本次C不能写成消融7的1/16。

取三次、八rank、64个投影smoke检查中的最大相对L2误差；相对BF16门槛5%、相对独立codec参考门槛1%，全部通过：

| 组别 | 最大相对BF16 L2 | 最大相对独立codec参考L2 |
| --- | ---: | ---: |
| C | 0.439100% | 0.008438% |
| A | 2.545994% | 0.017685% |
| B | 2.545994% | 0.017685% |
| Flux朴素 | 2.546476% | 0.000000% |
| Megatron朴素 | 2.546476% | 0.000000% |

每组的30条正式50步loss轨迹逐项一致；Flux朴素与Megatron朴素也逐项一致，A与B逐项一致。这是本批输入上的观测，不构成不同实现对任意输入逐位等价的证明。两个朴素baseline的正式调用为每投影200次，连同40次预热共240次；每份profile另核验256次共享编码、通信、解码调用，Flux组还须有256次GemmOnly标记。

冻结worker每窗口重新初始化模型并生成固定的4个合成微批，之后每步都用 `iter(batches)` 重复这些数据。朴素baseline的平均loss最低，但A/B的末步loss更低；C的末步loss约为A/B的9.375倍。平均loss受整个50步路径影响，末步loss只反映终点，不能只凭一种排序判断长期训练质量；本实验没有独立验证集或真实语料泛化评估。
