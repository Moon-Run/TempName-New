# H100 GPT6.7B TP8 消融实验7：改进到达优先与1/16选择性量化的50步实测

更新：2026-10-19。依据回传提交 `42d048eb`，汇总批次 `ablation6-then7-3x-50steps-20261019-162154-480841` 下消融7的三次独立比较。**三次均完成，每次36个正式窗口，合计108窗口、5400个正式optimizer step、864份正式rank记录。** 三次独立预检及严格报告均通过CPU离线重算。方案见[消融7定义](消融实验7-改进到达优先.md)，此前三次消融6另见[消融6结果](base-phase6-ablation6.md)。整批六次合计258窗口、12900正式step、2064份正式rank记录。

## 1. 实测结论

- **改进B相对A未显示稳定整步收益。** 三次B/A配对耗时下降为−0.151%、+0.119%、−0.096%，三个95%区间全部跨零；合并均值B为535.133 ms、A为534.908 ms。
- **关键机制事实：B的Attention、MLP均接受0次交换，映射与A完全相同。** 本批实际验证的是 `tail_residual` 的保守回退路径；尚未覆盖非identity重排的性能收益。A/B的微小计时差不能解释为新重排带来的提升，也不据此证明所有到达感知方法都无效。
- **1/16预算C仍最快：合并515.729 ms/step。** 相对A、改进B的合并均值耗时下降分别为3.586%、3.626%；三次C/A和C/B配对区间均完全为正。这是不同实现组合的总体差距，包含量化范围、codec、工作区与生命周期差异。
- C的平均loss较低（3.041341对3.821014），末步loss却较高（1.054098e-04对3.261156e-05）。这些指标来自固定合成微批的50步轨迹，不能单独据此断言真实训练精度优劣。

## 2. 三组定义与固定条件

| 组别 | 调度与实现 | 远端量化范围 |
| --- | --- | --- |
| C | 原candidate实现、原到达表、双工作区、实例持有配置/输出 | 按原校准pass0/1重选1/16预算mask |
| A | 基础交替，固定融合v2、单工作区、逐次配置/复位、输出clone | 全部远端贡献 |
| B（改进版） | 同A的计算/codec/生命周期，映射由 `tail_residual` 拟合；本批实际为identity | 全部远端贡献 |

本实验的B始终指改进版；C保留原到达表，只有量化预算改为1/16。本地贡献和既定GEMM/反向路径保持BF16/STE语义。B/A是同codec下调度净收益的主比较；C/A、C/B涉及多项差异。

环境为单节点 `gxn75`、8×NVIDIA H100 80GB HBM3、每卡132 SM，PyTorch2.6.0+cu124、运行CUDA12.4、NCCL2.21.5，`NCCL_NVLS_ENABLE=0`。模型为GPT6.7B：32层、H4096/FFN16384、32 heads、S2048、micro batch1/global batch4、TP8/DP1/PP1/CP1、BF16，seed1234、token_seed4321、padded vocab33792。所有组均覆盖32个Attention输出投影和32个MLP输出投影。

每窗口独立重置模型，预热10步后正式50步；每步4个微批、8192 token，每窗口409600个正式token。完整step包含前向、反向、通信、optimizer更新和清梯度，耗时为 `max(八rank elapsed_seconds) × 1000 / 50`。步数由 `execution_timing`、冻结worker配置和全部rank轨迹共同核验；继承的构建 `config.timed_steps=20` 仅为历史溯源元数据，不能作为本次计时分母。累计步数表示多个独立窗口的工作量。

## 8. 与消融6及历史实验的关系

消融6的C为1/64上限，本次C为1/16上限；两者合并均值分别为515.866和515.729 ms/step。该差值来自先后执行的不同实验，不能当作扩大预算的配对收益，预算影响应结合[专门的消融5](base-phase6-ablation5.md)解释。A的50步轨迹在消融6/7中相同，但两个实验的窗口也不互相配对。

旧B与改进B属于不同实验、不同时间段，本次没有同场旧B组，因此不计算“改进B相对旧B”的严格收益。C也没有改用B的新到达表；本页结论仅覆盖原C实现＋1/16 mask，以及改进B在这份校准证据上的identity回退。
